Extra Keys - macOS app

macOS App

I had long enjoyed using an external keypad during development to turn development environment key chords (multi-key shortcuts) into a single button. The Logitech G13, while marketed toward gaming, is an excellent device for this, reducing debugger command errors and wasted time. At the time I started using this, it could take several hours to reach a scenario in the debugger (computational modeling of complex algorithms), so a mistake could cost a lot of time. The software to run the G13 never was very good, and eventually wouldn't run on newer macOS versions, so I wrote a replacement which has seen some pretty good adoption by other owners of this hardware.

Services Provided

  • macOS app development
  • Graphical design
  • App deployment on the App Store

Technologies Used

  • macOS
  • Swift
  • IOKit
  • MVC
Available on the App Store: https://apps.apple.com/us/app/extra-keys/id1541973430?mt=12

WalletBase - macOS app

macOS App

I had an old password-wallet file sitting around that I needed to look inside, but the original software wouldn't run on newer macOS versions. So I thought it would be really fun to write a partial implementation of a password wallet software to read and display the contents, written entirely in SwiftUI. I am not crazy enough to want any liability associated with password security, so releasing it open source was a natural solution. It was a great opportunity to practice more SwiftUI beyond the day job, expand my SwiftUI experience into macOS, expand my SQL experience, and gain some cryptography experience.

Services Provided

  • macOS app development
  • Graphical design

Technologies Used

  • macOS
  • Swift
  • SwiftUI
  • SQL / SQLite3
  • CommonCrypto
Source available on GitHub: https://github.com/MarkJerde/WalletBase

Super Flash Cards - iOS app

iOS App

I was asked for an app that would display flash cards in a multiple-choice format, associating names with faces, bidirectionally. The result is an app that allows users to create their own flashcard decks, using either text or image for the questions and answers, can speak questions, and picks cards strategically to help you learn. Used with adults to learn names and faces as well as preschoolers to learn colors and letters.

Technologies Used

Word Find - iOS app

iOS App

What started as a mix between a UIKit technology demo and a funny joke turned into a game that I enjoyed enough to have to share publicly. We've all done word find puzzles where you have a list of words and a sea of letters. This app turns that around and gives you a single word, and a sea of very few letters over and over again. With false positives everywhere, you will almost find your word for quite a while.

Services Provided

  • iOS app development
  • Graphical design
  • App deployment on the App Store

Technologies Used

  • iOS
  • Swift
  • MVC
App Store review wasn't amused, even though I enjoy playing it. It might make it through now that I added a "fidget spring" word sheet (that part is fun, too), but I've had higher priorities.
